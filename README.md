# Background App Demo

Kotlin Android sample that demonstrates:

- **Foreground Service** — long-running work with a persistent notification
- **WorkManager** — periodic background work (15-minute minimum interval)

## Requirements

- Android Studio Ladybug+ (or compatible)
- JDK 17
- Android SDK 35

## Open & run

1. Open this folder in Android Studio
2. Let Gradle sync finish
3. Run on an emulator or device (API 26+)
